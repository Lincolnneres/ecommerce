# 🛒 Comércio Eletrônico

Plataforma de e-commerce completa com autenticação, carrinho de compras e pagamento integrado via MercadoPago.

## 🚀 Demo

🌐 [ecommerce-phi-nine-21.vercel.app](https://ecommerce-phi-nine-21.vercel.app)

## 🛠️ Tecnologias

**Frontend**
- React + Vite
- React Router DOM
- Axios
- Context API

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT (autenticação)
- MercadoPago SDK

## ✨ Funcionalidades

- Cadastro e login de usuários
- Listagem e detalhe de produtos
- Carrinho de compras
- Checkout com MercadoPago (Sandbox)
- Histórico de pedidos
- Painel administrativo

## 📦 Deploy

- Frontend: [Vercel](https://vercel.com)
- Backend: [Render](https://render.com)
- Banco de dados: [MongoDB Atlas](https://cloud.mongodb.com)
